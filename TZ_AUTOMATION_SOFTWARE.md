## 1. ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

### 1.1 Название проекта
**OctoMaster Pro** - Визуальный конструктор автоматизации для Octo Browser

### 1.2 Краткое описание
Революционная платформа для автоматизации работы с браузерами, которая позволяет **любому человеку** (даже без навыков программирования) создавать сложные сценарии автоматизации через визуальный интерфейс. Софт записывает действия пользователя, автоматически генерирует скрипты и предоставляет мощные инструменты для скрапинга, тестирования и автоматизации любых веб-задач.

### 1.3 Главная цель
Сделать автоматизацию браузера **настолько простой**, что даже новичок сможет за 5 минут создать рабочий скрипт, просто **показав** компьютеру что нужно делать.

### 1.4 Уникальное торговое предложение (USP)
- ✅ **Запись действий в реальном времени** - делайте что хотите, программа запомнит
- ✅ **AI-ассистент** - понимает что вы хотите сделать и помогает
- ✅ **Визуальный редактор** - собирайте скрипты как LEGO
- ✅ **Встроенный браузер** - всё в одном окне
- ✅ **Библиотека готовых блоков** - тысячи готовых решений
- ✅ **Интеграция с Octo Browser API** - полный контроль над профилями
- ✅ **Нулевой порог входа** - начните через 30 секунд после установки

## 3. ОСНОВНЫЕ ПРИНЦИПЫ И ФИЛОСОФИЯ

### 3.1 Принципы дизайна

1. **"Покажи, не говори"** (Show, Don't Tell)
   - Минимум текста, максимум визуала
   - Все действия видны и понятны
   - Интерактивные туториалы

2. **"Работает из коробки"** (Works Out of the Box)
   - Установка за 30 секунд
   - Готовые шаблоны для старта
   - Не нужно ничего настраивать

3. **"Прогрессивное усложнение"** (Progressive Complexity)
   - Новички видят только базовые функции
   - Продвинутые функции скрыты, но доступны
   - Плавный переход от простого к сложному

4. **"Одно окно для всего"** (Single Window Experience)
   - Всё в одном приложении
   - Не нужно переключаться между программами
   - Встроенный браузер, редактор, отладчик

5. **"Умные подсказки"** (Smart Hints)
   - AI понимает контекст
   - Предлагает следующее действие
   - Учится на ваших действиях

### 3.2 Философия разработки

**Делаем сложное простым:**
- Автоматизация не должна требовать знания программирования
- Интерфейс должен быть интуитивным как у мобильного приложения
- Ошибки должны объясняться человеческим языком

**Сила в гибкости:**
- Новички используют готовые блоки
- Профессионалы пишут свой код
- Все работают в одной программе

**Открытость и расширяемость:**
- Система плагинов
- API для интеграций
- Открытый формат файлов

### 4.2 Компоненты системы

#### 4.2.1 Frontend (Графический интерфейс)
- **GUI Framework:** PyQt6 или PySide6
- **Визуальный редактор:** Node-based graph editor (как в Blender/Unreal Engine)
- **Встроенный браузер:** QtWebEngine (Chromium)
- **Code Editor:** QScintilla с подсветкой синтаксиса Python

#### 4.2.2 Core Engine (Ядро)
- **Язык:** Python 3.11+
- **Execution Engine:** Async/await для параллельного выполнения
- **Script Storage:** JSON/YAML для хранения скриптов
- **State Management:** FSM (Finite State Machine) для управления состоянием

#### 4.2.3 Browser Automation
- **Primary:** Playwright (современный, быстрый, мощный)
- **Secondary:** Selenium (для совместимости)
- **Advanced:** Direct CDP (Chrome DevTools Protocol) для максимального контроля

#### 4.2.4 AI/ML Components
- **Intent Recognition:** Определение намерений пользователя
- **Smart Selectors:** Автоматический поиск надежных селекторов
- **Script Generation:** Генерация кода по описанию
- **Model:** Local LLM (Llama 3 / GPT-4-mini through API)

### 5.2 МОДУЛЬ 2: Рекордер действий (Action Recorder)

#### 5.2.1 Функция записи
**Главная фича:** Нажать "Запись" → сделать действия в браузере → Стоп → Получить готовый скрипт

**Что записывается:**
- Клики (левая/правая кнопка)
- Ввод текста
- Навигация (переходы по URL)
- Скроллинг
- Выбор из dropdown
- Drag & drop
- Нажатие клавиш
- Загрузка файлов
- Изменение viewport (размер окна)

**Умные алгоритмы:**
- **Smart Wait Detection:** Автоматическое определение когда нужно ждать
- **Element Grouping:** Группировка похожих действий
- **Loop Detection:** Определение циклических действий
- **Conditional Detection:** Определение условий (if/else)

#### 5.2.2 Генерация селекторов
**Проблема:** Найти надежный способ идентификации элемента

**Решение:** Генерировать несколько типов селекторов и выбирать лучший

**Типы селекторов:**
1. ID (`#button-submit`)
2. Class (`.btn.btn-primary`)
3. XPath (`//button[@type='submit']`)
4. CSS Selector (`div > button:nth-child(2)`)
5. Text содержимое (`button:contains('Submit')`)
6. Data атрибуты (`[data-testid='submit-btn']`)
7. AI Selector (умный поиск по контексту)

**Приоритет селекторов:**
1. Data атрибуты (самые надежные)
2. ID
3. Уникальные классы
4. AI Selector
5. XPath (наименее надежный)

**Проверка селекторов:**
- Проверка уникальности (должен находить только 1 элемент)
- Проверка стабильности (не меняется при обновлении страницы)
- Fallback селекторы (если первый не сработал, пробуем второй)

#### 5.2.3 Post-processing записи
После остановки записи:
- Показать timeline всех действий
- Возможность удалить ненужные шаги
- Объединить повторяющиеся действия в цикл
- Добавить проверки (assertions)
- Оптимизация ожиданий

#### 5.2.4 Режимы записи
1. **Базовый режим:** Записывает все подряд
2. **Умный режим:** AI анализирует и оптимизирует
3. **Режим теста:** Добавляет проверки (assertions)
4. **Режим скрапинга:** Фокус на извлечении данных

### 5.4 МОДУЛЬ 4: AI Ассистент

#### 5.4.1 Генерация скриптов по описанию
**Вход:** Текстовое описание задачи на русском/английском

**Примеры:**
```
"Зайди на google.com и найди информацию про Python"
→ Генерирует: Открыть google.com → Ввести в поиск "Python" → Клик по кнопке поиска

"Собери все заголовки статей с habr.com"
→ Генерирует: Открыть habr.com → Найти все h2 → Извлечь текст → Сохранить в CSV

"Залогинься на сайт с почтой test@mail.com и паролем 123"
→ Генерирует: Открыть сайт → Найти поле email → Ввести test@mail.com → ...
```

**Алгоритм:**
1. Парсинг описания (NLP)
2. Определение намерений (Intent Recognition)
3. Разбивка на шаги
4. Генерация блоков
5. Проверка логики
6. Показ пользователю для подтверждения

#### 5.4.2 Умное предложение действий
**Контекстный анализ:**
- Анализирует текущую страницу
- Понимает что на ней есть
- Предлагает возможные действия

**Примеры:**
- Видит форму логина → "Хотите заполнить форму?"
- Видит таблицу с данными → "Хотите извлечь данные из таблицы?"
- Видит пагинацию → "Хотите собрать данные со всех страниц?"

#### 5.4.3 Исправление ошибок
**Когда скрипт падает:**
1. AI анализирует ошибку
2. Понимает причину (элемент не найден, таймаут, и т.д.)
3. Предлагает исправление:
   - "Попробовать другой селектор?"
   - "Увеличить время ожидания?"
   - "Добавить скроллинг до элемента?"

#### 5.4.4 Оптимизация скриптов
**Auto-optimization:**
- Убирает ненужные ожидания
- Объединяет похожие действия
- Распараллеливает независимые действия
- Добавляет error handling
- Улучшает селекторы

#### 5.4.5 Natural Language Query
**Чат с AI:**
```
Пользователь: "Как мне извлечь все ссылки со страницы?"
AI: "Используйте блок 'Извлечь данные' с селектором 'a' и атрибутом 'href'.
```

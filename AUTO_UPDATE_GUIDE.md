# 🔄 Система автоматических обновлений

## Обзор

OctoMaster Pro теперь имеет **встроенную систему автоматических обновлений** через Git. Больше не нужно каждый раз скачивать архив и переустанавливать все заново!

## Как использовать

### Проверка обновлений

**Способ 1: Через меню**
```
Help → 🔄 Check for Updates...
```

**Способ 2: Автоматически**
- При запуске программа может проверять обновления (настраивается)

### Установка обновления

1. **Откройте меню**: `Help → Check for Updates`
2. **Дождитесь проверки** - программа автоматически проверит наличие обновлений
3. **Если обновление доступно**:
   - Вы увидите количество новых коммитов
   - Список изменений (changelog)
   - Кнопку "⬇️ Install Update"
4. **Нажмите "Install Update"**
5. **Выберите опции**:
   - ✅ Update dependencies - обновить Python пакеты (рекомендуется)
6. **Дождитесь завершения**
7. **Перезапустите приложение**

## Что сохраняется при обновлении

✅ **Сохраняется:**
- Ваши workflow (.json файлы в projects/)
- Настройки Octo Browser (.octo_settings)
- Настройки приложения
- Пользовательские плагины
- История проектов

❌ **НЕ сохраняется:**
- Изменения в исходном коде программы (будут перезаписаны)

## Что происходит при обновлении

1. **Git fetch** - скачивание информации о новой версии
2. **Stash local changes** - временное сохранение ваших изменений (если есть)
3. **Git pull** - загрузка новой версии
4. **Apply stash** - восстановление ваших настроек
5. **pip install -r requirements.txt** - обновление зависимостей (опционально)

## Технические детали

### Для разработчиков

Система обновлений использует:
- **Git** для контроля версий
- **subprocess** для выполнения Git команд
- **QThread** для фоновых операций
- **Stash/Pop** для сохранения локальных изменений

### Файлы системы обновления:
- `octomaster/core/updater.py` - Core updater logic
- `octomaster/gui/dialogs/update_dialog.py` - Update UI dialog
- `octomaster/gui/main_window.py` - Menu integration

## Troubleshooting

### Проблема: "Not a Git repository"

**Причина:** Вы скачали проект как ZIP архив, а не клонировали через Git.

**Решение:**
```bash
# Вместо скачивания ZIP, клонируйте репозиторий:
git clone https://github.com/your-username/auto-octo-easy.git
cd auto-octo-easy
pip install -r requirements.txt
python main.py
```

### Проблема: "Failed to check for updates"

**Возможные причины:**
1. Нет подключения к интернету
2. Git не установлен
3. Проблемы с доступом к репозиторию

**Решение:**
```bash
# Проверьте Git:
git --version

# Проверьте подключение:
git fetch origin

# Обновите вручную:
git pull origin <your-branch>
```

### Проблема: "Update failed: local changes"

**Причина:** У вас есть несохраненные изменения в исходном коде.

**Решение 1 (автоматически):**
- Программа автоматически сделает stash ваших изменений
- Обновится
- Попытается применить изменения обратно

**Решение 2 (вручную):**
```bash
# Сохраните изменения:
git stash push -m "My local changes"

# Обновите:
git pull origin <branch>

# Верните изменения:
git stash pop
```

### Проблема: "Dependencies update failed"

**Причина:** Ошибка при установке Python пакетов.

**Решение:**
```bash
# Обновите вручную:
pip install -r requirements.txt --upgrade

# Или с определенным пакетом:
pip install <package-name> --upgrade
```

## Ручное обновление (альтернатива)

Если автоматическое обновление не работает:

```bash
# 1. Сохраните свои файлы
cp .octo_settings ../octo_settings_backup.json
cp -r projects/ ../projects_backup/

# 2. Обновите код
git pull origin <your-branch>

# 3. Обновите зависимости
pip install -r requirements.txt --upgrade

# 4. Восстановите настройки (если нужно)
cp ../octo_settings_backup.json .octo_settings
cp -r ../projects_backup/* projects/

# 5. Перезапустите
python main.py
```

## Best Practices

### ✅ Рекомендуется:
- Проверяйте обновления раз в неделю
- Обновляйте dependencies при обновлении
- Делайте backup важных workflow перед обновлением
- Читайте changelog перед установкой обновления

### ❌ НЕ рекомендуется:
- Изменять исходный код программы напрямую (лучше используйте плагины)
- Пропускать обновление dependencies
- Обновляться во время выполнения важных задач

## FAQ

### Q: Как часто выходят обновления?

A: Обновления выходят по мере добавления новых функций и исправления багов. Обычно 1-2 раза в неделю для активных веток.

### Q: Нужен ли интернет для обновления?

A: Да, нужен для скачивания обновлений из Git репозитория.

### Q: Сколько времени занимает обновление?

A: Обычно 10-30 секунд для скачивания кода + 1-3 минуты для обновления dependencies (если выбрано).

### Q: Можно ли откатиться к предыдущей версии?

A: Да, через Git:
```bash
git log  # найдите hash предыдущей версии
git checkout <commit-hash>
```

### Q: Что делать если обновление сломало что-то?

A:
1. Сообщите об ошибке в Issues
2. Откатитесь к предыдущей версии (см. выше)
3. Или обновитесь к последнему фиксу
